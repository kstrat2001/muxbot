# What Mux Bot does

Mux Bot is the guide on Home. It helps you get set up (darkmux, pairing, models, GitHub), makes your first bot from a repo, and answers questions about Mux Bot and darkmux from these help articles. When the articles don't cover something, it says it doesn't know.

## What it doesn't do

Mux Bot doesn't start work itself. Work happens in a bot's thread, where the bot proposes it and you approve it.

## Settings

Ask Mux Bot about a setting and it explains it and shows the switch right in the chat. Changing the switch changes the setting.
