# Roadmap

Mux Bot helps you build web apps with local AI: pick what you want to get done, get a working project with a live preview, and keep improving it one approved run at a time. darkmux, on your Mac, runs the models and the work.

The work is tracked in three GitHub issues, each with its features as sub-issues. The issues are the source of truth for status. This page says what each stage is for.

## 1. MVP: start a site and keep improving it ([#10](https://github.com/kstrat2001/muxbot/issues/10))

- Start a project from a template: a website (Vite + React) or a book.
- Or work on a project you already have, with its preview and playbook set up after you approve.
- Every run waits for Approve, commits itself, and can be undone. Reply to change it.
- A live preview beside the conversation, with clear reasons when it can't run.

## 2. Soft launch ([#11](https://github.com/kstrat2001/muxbot/issues/11))

- Finished bot characters and an App Store listing.
- darkmux's app connection installs in one step.
- Help articles that match what ships.

## 3. Next ([#12](https://github.com/kstrat2001/muxbot/issues/12))

- Edit text by hand in the preview.
- A starter model picked for your Mac's memory, and a visible "starting the model" step.
- Start runs from iPhone, then choose which Mac runs them.
- More templates: articles, then web apps with accounts and data.
- Run and share darkmux evals from the app.
- Bots that remember lessons from past runs.

## How to add to it

Open an issue describing the problem and who it helps. Adding a use case is a new template repo and an entry in [muxbot-templates](https://github.com/kstrat2001/muxbot-templates), with no app code. Features that need darkmux link the darkmux issue they depend on.
